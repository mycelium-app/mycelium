Get started

Run it on
your own machines.

One control plane, plus a node on each machine that runs agents.

WebLinux desktopAndroid

Start the control plane with Docker Compose, install the agent adapters, then join each machine with one command. The README has the full guide, including NixOS and the settings for serving it beyond localhost.
