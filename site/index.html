Mycelium

Your coding agents, on every machine, in one place.

Mycelium is a self-hosted control plane that runs Claude Code and Codex on each machine you own, and lets you steer every conversation from the browser, the desktop or your phone.

And the rest

  • Git panel

    Stage, commit, amend, sign off, skip hooks, then publish, push or pull. A branch picker and a graph of every branch.

  • Walkthroughs

    Steps grouped into sections, a scope picker, and the ones you have read remembered.

  • Chats

    Anthropic, Ollama and OpenRouter. Switch model mid-chat, or import a claude.ai export.

  • Projects and groups

    Clone or create from GitHub and GitLab, sort by last update, assign to groups and pin conversations.

  • Accounts and usage

    Several logins per agent, with each usage window kept, its reset time and a projection.

  • Nodes

    Give each machine a colour. At the session limit it closes the least recently used idle session.

  • Schedules

    Cron in your time zone, or proposed by an agent from a conversation and confirmed by you.

  • Terminals

    A terminal panel on tmux, so the full terminal app survives the client closing.

  • History

    Turns, tokens and an estimated cost for every conversation, and search across every transcript.

Install

  1. Run the control plane

    One container and a Postgres database. The web client comes with it.

  2. Add your machines

    curl -fsSL https://github.com/mycelium-app/mycelium/releases/latest/download/install.sh | sh -s -- https://your-control-plane

    Approve the code it prints, and the machine appears in your list. NixOS, nix-darwin and home-manager modules are in the flake.

  3. Open a conversation

    In the browser, or the Linux desktop app.

Download

  • ReleasesAndroid APK, Linux desktop as .deb or .tar.gz, and the node binary, each with a SHA-256.
  • Latest versionThe tag the installer takes, as plain text.
  • Install guideFor you or for your agent. Nix modules and the container image are in it.

Full steps, written so you can hand them to your agent: example.com/mycelium/install.md
