Install

  1. Run the control plane

    One container and a Postgres database. The web client comes with it.

  2. Add your machines

    curl -fsSL https://github.com/mycelium-app/mycelium/releases/latest/download/install.sh | sh -s -- https://your-control-plane

    Approve the code it prints, and the machine appears in your list. NixOS, nix-darwin and home-manager modules are in the flake.

  3. Open a conversation

    In the browser, or the Linux desktop app.

Full steps, written so you can hand them to your agent: example.com/mycelium/install.md
